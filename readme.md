# Sample App – CI/CD Pipeline Lab

Deze map bevat een **sample Flask applicatie** gebruikt in een CI/CD-lab met Jenkins.

## Doel van het lab
- Code pushen naar GitHub
- Jenkins gebruiken om builds te starten
- Applicatie containerizen met Docker
- CI/CD pipeline opzetten en testen

## Inhoud
- Flask applicatie (`sample_app.py`)
- Bash script voor Docker build & run
- Templates en static files
- Dockerfile (gegenereerd via script)

## Context
Lab gebaseerd op **“Build a CI/CD Pipeline Using Jenkins”** (DevNet Associate).
